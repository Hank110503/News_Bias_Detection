# 多模态任务训练方案文档

## 1. **任务概述**

1. 本任务旨在通过多模态输入（新闻图像 + 文本），定量预测多维度的偏见线索（cues），并为每个线索输出推理过程（`reason`）、存在与否（`present`）以及严重程度（`score`）。任务依托 V-T-J-D 评估体系，分为三个主要特征层级：
   1. **纯视觉特征预测（Visual Cues）**：分析图像本体特征，如视觉显著性、构图极性等。
   2. **纯文本特征预测（Textual Cues）**：分析文本特征，如实体标签、情感倾向等。
   3. **图文联合特征预测（Joint/Coherence Cues）**：结合图像和文本的跨模态交互，评估图文关联性与整体叙事框架。

## 2. **数据结构**

- ### 2.1 数据样本结构

  - **`text`**：新闻事件背景文本。

  - **`image`**：图像路径。

  - **特征观察（输出侧）**：

    - `visual_observation`：纯视觉层面的客观描述。
    - `textual_observation`：纯文本层面的客观描述。
    - `joint_mechanism`：图文对齐与联合机制的初步分析。

  - **`cues`（输出侧标签）**：包含 10 条偏见线索。对于每条线索：

    - `reason`：模型的推理过程（**必须放在首位**）。

    - `present`：cue 是否存在（布尔值）。注意，当score=0的时候，present必须是false，请用机制确保这一点。

    - `score`：cue 的分数（0、1、2，3）。

      

      **`consistency_dimension`（输出侧标签）**：图片和文章的关系

      - `reason`：模型的推理过程（**必须放在首位**）。
      - `D1_Relationship_Type`:严格限制Reinforcing / Contrastive / Supplementary三选一

### 示例数据样本：

## 3. **模型结构设计**

### 3.1 **多模态模型架构**

采用 `Qwen2.5-VL-7B` 作为基座模型。利用模型内置的视觉编码器、文本编码器和 LLM 基座，将所有预测任务转化为**单一的 Next-Token Prediction（自回归生成）任务**。

### 3.2 **训练目标**

#### 模型架构：

1. **图像编码器**：使用 `Qwen2.5-VL-7B` 中的视觉编码器（例如 ViT）来处理图像输入，输出图像的嵌入表示。
2. **文本编码器**：使用 `Qwen2.5-VL-7B` 中的文本编码器（例如 Transformer）来处理文本输入，输出文本的嵌入表示。
3. **融合层**：将图像和文本的嵌入进行拼接或其他形式的融合，生成联合表示。
4. **任务头**（LoRA头）：通过一个单一的任务头来处理所有的 cue 预测任务，任务头基于融合后的多模态表示来预测每个 cue 的 `present`、`score` 和 `reason`。

### 3.2 **训练目标**

- 训练目标是让模型根据图像和文本输入，分别预测各个 cue 的 `present`、`score` 和 `reason`，并通过训练让模型学会根据推理过程（`reason`）来做出最终的预测。

- 模型分为两阶段训练：

  Stage 1（理解阶段）

  image + text → observation + joint

  Stage 2（推理阶段）

  image + text + observation + joint → cues

# 4️⃣ 核心：多模态 DataCollator

```
from PIL import Image
import torch

class QwenVLDataCollator:
    def __init__(self, processor):
        self.processor = processor

    def __call__(self, batch):
        texts = []
        images = []

        for example in batch:
            messages = build_messages(example)

            # 👉 把对话转成模型输入格式
            text = self.processor.apply_chat_template(
                messages,
                tokenize=False,
                add_generation_prompt=False
            )

            image = Image.open(example["image_path"]).convert("RGB")

            texts.append(text)
            images.append(image)

        # 👉 同时处理 text + image
        model_inputs = self.processor(
            text=texts,
            images=images,
            padding=True,
            return_tensors="pt"
        )

        # =========================
        # 🔥 label mask（关键！！）
        # =========================
        labels = model_inputs["input_ids"].clone()

        for i, example in enumerate(batch):
            messages = build_messages(example)

            prompt_text = self.processor.apply_chat_template(
                messages[:-1],  # 去掉assistant
                tokenize=True
            )["input_ids"]

            labels[i, :len(prompt_text)] = -100

        model_inputs["labels"] = labels
        return model_inputs
```

## 5. **推理过程**

### 5.1 **推理任务**

###  **推理输出格式**

推理时，传入图像和文本。推荐结合结构化输出工具（如 `Outlines` 库），确保输出的 JSON 格式 100% 合法，且严格遵循 `reason -> present -> score` 的顺序。

## 两阶段推理（推荐）

为与训练阶段保持一致，本项目采用显式推理流程：

------

### Step 1：Observation 生成

```
(image + text) → (visual_observation + textual_observation + joint_mechanism)
```

------

### Step 2：Cue 推理

```
(image + text + observation) → (cues + consistency_dimension)
```

------

该模式能够显著提升推理稳定性与可解释性。

## ### 5.2 推理实现

------

### 🔹 Step 1：生成 Observation

```
def infer_stage1(model, processor, text, image):
    messages = [
        {
            "role": "system",
            "content": "Generate structured multimodal observations."
        },
        {
            "role": "user",
            "content": [
                {"type": "image", "image": image},
                {"type": "text", "text": f"Text: {text}"}
            ]
        }
    ]

    prompt = processor.apply_chat_template(
        messages,
        tokenize=False,
        add_generation_prompt=True
    )

    inputs = processor(
        text=[prompt],
        images=[image],
        return_tensors="pt"
    ).to(model.device)

    outputs = model.generate(**inputs, max_new_tokens=512)
    result = processor.decode(outputs[0], skip_special_tokens=True)

    return result
```

```
def infer_stage2(model, processor, text, image, observation):
    messages = [
        {
            "role": "system",
            "content": "Predict bias cues based on observations."
        },
        {
            "role": "user",
            "content": [
                {"type": "image", "image": image},
                {
                    "type": "text",
                    "text": f"""
Text: {text}

[Observations]
{observation}
"""
                }
            ]
        }
    ]

    prompt = processor.apply_chat_template(
        messages,
        tokenize=False,
        add_generation_prompt=True
    )

    inputs = processor(
        text=[prompt],
        images=[image],
        return_tensors="pt"
    ).to(model.device)

    outputs = model.generate(**inputs, max_new_tokens=1024)
    result = processor.decode(outputs[0], skip_special_tokens=True)

    return result
```
